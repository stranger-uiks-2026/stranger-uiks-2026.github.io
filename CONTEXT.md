# Контекст проекта Stranger UIKs 2026

Источник обсуждения: `codex://threads/01a0cabb-dbe1-7122-8c8c-5215128b1cc0`.

## Проект

Интерактивная карта результатов выборов в Госдуму 2026 года для поиска различий между соседними УИК. Публичный сайт: https://stranger-uiks-2026.github.io/. Репозиторий: https://github.com/stranger-uiks-2026/stranger-uiks-2026.github.io. Эта папка — копия локального репозитория из исходной сессии с сохранённой Git-историей и `origin`.

## Принятые решения

- Название сайта: Stranger UIKs 2026. Подзаголовок: «Изнанка выборов - разница в результатах на соседних участках».
- Состояние карты хранится в URL через History API. Для регионов есть короткие пути, для ТИК — короткие идентификаторы; карточка УИК имеет постоянную ссылку.
- Можно выбирать регион, район или группу ТИК, показатель, режим контрастных пар или всех УИК, расстояние, порог различия и процентный диапазон.
- В режиме контрастных пар достаточно, чтобы один УИК пары попадал в выбранный процентный диапазон.
- Есть поиск по номеру УИК. Близкие точки собираются в кластер с круговой диаграммой; цвет секторов соответствует значениям выбранного показателя.
- Последняя согласованная цветовая схема основана на Cividis с медным диапазоном 60–79% и алым 80–100%. Разделители секторов убраны.
- Данные регионов находятся в `data/`. По умолчанию при отсутствии региона выбирается случайный регион.
- Последнее опубликованное исправление: при смене региона список районов обновляется сразу.

## Данные и ограничения

Первичные данные выборов: https://deg.zhizhin.xyz/shpilkin.html. Координаты УИК были сопоставлены с данными 2021 года; подробности и оговорки есть в `README.md`. Группы районов находятся в `area-groups.json` и `moscow-areas.json`.

Исходная сессия содержит подробное обсуждение и проверки публикаций. Этот файл фиксирует рабочий контекст, а код и данные взяты из её локального репозитория.
