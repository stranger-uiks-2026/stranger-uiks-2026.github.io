# Stranger UIKs 2026

## Работа над проектом

Это Git-репозиторий с `origin` на GitHub. Новую локальную копию можно получить командой `git clone https://github.com/stranger-uiks-2026/stranger-uiks-2026.github.io.git`. Краткая история решений из исходной сессии находится в `CONTEXT.md`.

Для изменений с несколькими шагами используйте OpenSpec: `openspec init` уже выполнен для Codex, Claude Code, Cursor и GitHub Copilot. Начать предложение можно через `$openspec-propose` в Codex, `/opsx:propose` в Claude Code или `/opsx-propose` в Cursor и Copilot. Спецификации и изменения хранятся в `openspec/`. Для работы CLI нужен установленный `@fission-ai/openspec` и Node.js 20.19+.

Статический сайт для GitHub Pages. Выберите регион, для Москвы — административный округ, для Петербурга, Воронежа и ещё 46 городов — район или группу городских ТИК, одну или несколько ТИК, показатель, расстояние и порог разницы. Линии связывают близкие УИК с контрастными результатами. Фильтры сохраняются в адресе страницы. Регион можно указать названием или кодом из `index.json`, например `?region=83`; для каждого региона работает короткий адрес, например `/spb/`, `/msk/` или `/altai-krai/`. При выборе региона сайт формирует короткую ссылку. Все прямые адреса обслуживает общая страница `404.html`; GitHub Pages возвращает для них HTTP 404, хотя приложение открывается нормально. У каждого УИК есть постоянная ссылка на карточку с результатами и картой ближайших соседей.

В меню «Отображение» режим `view=all` показывает все УИК выбранной территории без линий и списка контрастных пар. Близкие точки по-прежнему сворачиваются в круговой значок, который открывается нажатием. Если для УИК отсутствует выбранный показатель, он показан серым. На узком экране фильтры идут перед картой, а список пар — после карты.

## Публикация

Скопируйте содержимое этой папки в корень репозитория GitHub. В настройках репозитория выберите **Pages → Deploy from a branch → main / root**. Сборка не требуется.

Локально: `python3 -m http.server 8000` в этой папке, затем откройте `http://localhost:8000`.

## Данные и ограничения

Исходный код проекта распространяется по [лицензии MIT](LICENSE). Внешние исходные данные и картографическая подложка сохраняют условия своих правообладателей; ссылки на источники приведены ниже.

- Протоколы 2026: https://deg.zhizhin.xyz/shpilkin.html (снимок от 22.09.2026).
- Показатель `metric=pick` берёт `pick_pct`, `pick_votes`, `pick_name` и `district` из того же файла протоколов. Это процент и число голосов за кандидата IditeNa в одномандатном округе, а не результат партийного списка. При отсутствии результата УИК не участвует в сравнении по этому показателю. Для него пары из разных округов не составляются.
- Координаты: https://github.com/Basistiy/duma/blob/master/data/edata.csv (набор 2021 года).
- Сопоставление по точному названию региона и номеру УИК. Повторяющиеся номера в наборе координат, ДЭГ, записи без значений и УИК с менее чем 100 избирателями исключены.
- Исторические координаты требуют проверки перед выводами: УИК могли переехать или сменить номер. Точки обозначают помещения голосования, не границы участков. Пространственная близость не доказывает аномалию сама по себе.
- Подложка карты: OpenStreetMap; Leaflet загружается с CDN. Для работы нужна сеть.

Готовые региональные JSON хранятся в папке `data/`; браузер подгружает только выбранный регион.

Группы районов Москвы составлены по [перечню Молодёжных палат Москвы](https://dk.mos.ru/map/), опубликованному ГБУ города Москвы. Все 132 названия ТИК московского набора сопоставлены с районами перечня. Выбор округа сохраняется в параметре `area`, например `/msk/?area=cao`.

На общей карте УИК рядом друг с другом собраны в значок с числом участков. Нажатие показывает все УИК группы с явкой, процентом ЕР и, если есть данные, голосами за кандидата IditeNa. УИК с одинаковыми координатами остаются в одной группе при любом масштабе. Постоянные подписи убраны.

Районы Петербурга сопоставлены с ТИК №1–64 по [официальному решению Санкт-Петербургской избирательной комиссии №172-6](https://tik7.spbik.spb.ru/tik/7/172-6.pdf). Для Воронежа доступны шесть городских районов, совпадающих с названиями ТИК в наборе. Код района передаётся в `area`. Параметр `tik` теперь принимает короткий код (например, `16` в Петербурге или `vrn-sov` в Воронеже); ссылки с полным названием ТИК по-прежнему работают.

Для ещё 46 городов в 39 регионах группы сформированы из названий городских ТИК в исходном наборе. Если один район представлен несколькими нумерованными ТИК, они объединены. Названия районов выводятся из названий ТИК; перед использованием для административных выводов их следует сверять с актуальными границами.

Одиночная точка окрашивается по выбранному показателю. Для нескольких близких УИК круг делится на равные сектора по одному на УИК; цвет каждого сектора соответствует проценту этой УИК. Среднее и диапазон значений показаны при нажатии на круг. Цветовая шкала и описание размещены рядом с фильтрами.

Цвет значков: пять дискретных ступеней на основе Cividis с медной ступенью 60–79% и алой ступенью 80–100% (0–19, 20–39, 40–59, 60–79, 80–100%). При масштабе карты от 14 рядом с круговой диаграммой группы показан диапазон процентов, а одиночный УИК показан значком с процентом.

Основа палитры Cividis: [Nuñez et al., PLOS ONE](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0199239). На карте используются пять контрастных ступеней на её основе для заметного различия 30% и 60%; точные значения остаются в подписи и карточке.

Региональные файлы `01.json`–`84.json` хранятся в папке `data/`; индекс регионов и группировка районов находятся в корне.
