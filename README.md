# Stranger UIKs 2026

Статический сайт для GitHub Pages. Выберите регион, показатель, расстояние и порог разницы. Линии связывают близкие УИК с контрастными результатами.

## Публикация

Скопируйте содержимое этой папки в корень репозитория GitHub. В настройках репозитория выберите **Pages → Deploy from a branch → main / root**. Сборка не требуется.

Локально: `python3 -m http.server 8000` в этой папке, затем откройте `http://localhost:8000`.

## Данные и ограничения

- Протоколы 2026: https://deg.zhizhin.xyz/shpilkin.html (снимок от 22.09.2026).
- Координаты: https://github.com/Basistiy/duma/blob/master/data/edata.csv (набор 2021 года).
- Сопоставление по точному названию региона и номеру УИК. Повторяющиеся номера в наборе координат, ДЭГ, записи без значений и УИК с менее чем 100 избирателями исключены.
- Исторические координаты требуют проверки перед выводами: УИК могли переехать или сменить номер. Точки обозначают помещения голосования, не границы участков. Пространственная близость не доказывает аномалию сама по себе.
- Подложка карты: OpenStreetMap; Leaflet загружается с CDN. Для работы нужна сеть.

Готовые региональные JSON включены в корень репозитория; браузер подгружает только выбранный регион.
