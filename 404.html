Как читать карту

Линия соединяет две ближайшие комиссии с разницей выше порога. Для каждой УИК ищутся до трёх ближайших соседей в пределах заданного расстояния. Разница измеряется в процентных пунктах. Щелчок по линии показывает обе УИК и исходные значения. Цвет одиночной точки показывает значение выбранного показателя по пяти ступеням шкалы на основе Cividis с медной и алой верхними ступенями: 30% и 60% относятся к разным контрастным ступеням. Каждый сектор круговой диаграммы соответствует одному УИК в группе и окрашен по его значению. При приближении на значках появляются процент одиночного УИК или диапазон группы. Для показателя «Кандидат IditeNa» сравниваются доли голосов за кандидата, выбранного проектом для соответствующего одномандатного округа. УИК без результата кандидата не участвуют в сравнении; пары между разными округами исключены. Нажатие на группу открывает список всех УИК с результатами. Близость определяется по точкам помещений для голосования, а не по границам участков.

Резкая разница помогает выбрать пару для проверки, но сама по себе не доказывает нарушение: на результат влияют состав избирателей, специальные участки, особенности округов и ошибки координат.

Данные

Протоколы выборов 2026 года: deg.zhizhin.xyz. Координаты: открытый набор УИК 2021 года, сопоставление по названию региона и номеру УИК. Координаты исторические и могут не отражать перенос УИК к выборам 2026 года. Неоднозначные и отсутствующие совпадения исключены; показывается охват для выбранного региона. ДЭГ исключено. Для процентов ЕР используется федеральный список. Для кандидата IditeNa используется поле pick_pct из файла протоколов источника.
